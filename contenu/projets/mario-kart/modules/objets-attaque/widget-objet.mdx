Le joueur doit voir quel objet il a en main. On ajoute au HUD une **case d'objet** : l'icône de l'objet, « x3 » pour un objet à plusieurs utilisations, et une roulette d'icônes pendant le tirage.

Comme les autres widgets du module 4, c'est une classe C++ pour la logique et un Widget Blueprint pour l'apparence. Le widget n'invente rien : il **écoute** les <Terme id="delegate">delegates</Terme> du composant d'objet du kart (`OnItemChanged` et `OnRouletteStarted`, vus dans le module Objets bonus). Dans cette leçon : le header du widget, puis les lignes ajoutées au PlayerController pour le créer.
