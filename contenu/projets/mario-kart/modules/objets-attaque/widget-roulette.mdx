Le `.cpp` de la case d'objet a deux rôles. D'abord, trouver le composant d'objet du kart du joueur et s'abonner à ses delegates, même si le kart n'existe pas encore quand le widget est créé. Ensuite, afficher : l'icône et le nombre d'utilisations quand l'objet change, et le défilement des icônes pendant la roulette.

## La roulette, image par image

<CodePasAPas fichier="KartItemWidget.cpp" debut={96} fin={118}>
  <Etape lignes="96-98" titre="Signature et Super">
    `NativeTick` est appelé à chaque image tant que le widget est affiché.
  </Etape>
  <Etape lignes="100-104" titre="Rien à animer">
    Pas de roulette, ou une table vide : on sort. Le test de la table vide protège aussi le calcul du modulo plus bas, qui diviserait par 0.

  <Etape lignes="106-111" titre="Attendre le bon moment">
    On accumule le temps des images. Tant qu'on n'a pas atteint 0,08 seconde, on sort. Sinon on retire 0,08 au lieu de remettre à 0 : le temps en trop n'est pas perdu, et la roulette garde un rythme régulier.
  </Etape>
  <Etape lignes="113-114" titre="L'icône suivante">
    Le <Terme id="modulo">modulo</Terme> fait boucler l'index : avec 4 objets dans la table, 0, 1, 2, 3, puis de nouveau 0.
  </Etape>
  <Etape lignes="116-118" titre="L'afficher">
    On lit l'objet de cette ligne de la table et on affiche son icône. Une ligne de table sans objet donne une case vide un instant.

<Encadre type="retenir">
Le widget ne décide de rien : il ne tire pas l'objet, il ne compte pas les utilisations. Il affiche ce que le composant lui envoie. Si on supprime le widget, le jeu marche toujours.
</Encadre>

## Dans l'éditeur : la case d'objet

1. Crée un Widget Blueprint `WBP_ItemSlot`, puis dans Graph > Class Settings, mets sa classe parente sur `KartItemWidget`.
2. Dans le Designer, ajoute une Image nommée exactement `ItemIcon` et un Text nommé exactement `UsesText`. Place la case dans un coin de l'écran.
3. Dans `BP_KartPlayerController`, choisis `WBP_ItemSlot` dans `Item Widget Class`.
4. Lance le jeu et roule dans une boîte : les icônes défilent pendant 2 secondes, puis l'objet s'affiche.
