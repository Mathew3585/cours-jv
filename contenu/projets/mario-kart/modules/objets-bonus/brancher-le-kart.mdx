Tout est prêt, sauf le kart lui-même. Le `AKartPawn` que tu as écrit au module 1 ne sait pas qu'il a une poche, et aucune touche n'utilise d'objet. On **revient donc dans un fichier déjà écrit** pour le faire évoluer. C'est normal dans un vrai projet : le code grandit avec le jeu, et une bonne structure permet d'ajouter sans tout casser.

Dans cette leçon, on ne voit que les lignes **ajoutées** pour les objets bonus. Les autres ont été expliquées au module 1. Les lignes du tête-à-queue (`SpinOut`) sont aussi dans ces fichiers, mais on les verra au module suivant : saute-les pour l'instant.
