Avant d'avoir de beaux widgets, il faut pouvoir **voir** que le compte à rebours et le chrono marchent. Le GameMode écrit donc ses informations directement à l'écran, en texte de debug. Une case à cocher, `bShowDebugText`, allume ou éteint tout ça.

Ces textes sont des **post-it** collés sur l'écran : moches, mais immédiats. Quand les widgets sont prêts, on décoche la case et ils disparaissent, sans toucher au code.

<Encadre type="retenir">
La **clé** d'un message de debug, c'est son emplacement à l'écran. Même clé : le nouveau message remplace l'ancien. Clés différentes : les messages s'affichent ensemble. Ici, 100 pour le compte à rebours et 101 pour le chrono.
</Encadre>

Le kart utilise aussi cette case : dans son BeginPlay, il lit `IsDebugTextEnabled()` une seule fois pour savoir s'il doit afficher son propre debug. Une seule case dans le GameMode règle donc le debug de toute la course.
