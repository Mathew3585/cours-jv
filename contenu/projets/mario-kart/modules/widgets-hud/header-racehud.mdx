## Les derniers réglages

Le texte de fin se change dans **Class Defaults**, catégorie Kart > Race (`Finished Text`). Enfin, ouvre `BP_KartPlayerController` et choisis `WBP_RaceHud` dans la case `Race Hud Widget Class`. Les deux cases de la catégorie Kart > UI sont maintenant remplies.

<Encadre type="piege">
Si `WBP_RaceHud` a été créé avec `UserWidget` comme parent, il n'apparaît pas dans la case `Race Hud Widget Class` : elle n'accepte que les classes qui héritent de `UKartRaceHudWidget`. Change sa Parent Class dans Class Settings.
</Encadre>
