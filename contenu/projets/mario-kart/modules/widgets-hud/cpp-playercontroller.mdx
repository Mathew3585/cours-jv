</Encadre>

## Dans l'éditeur : le Blueprint du PlayerController

Les deux cases `TSubclassOf` se remplissent dans un Blueprint. Crée (ou ouvre) `BP_KartPlayerController`, un Blueprint dont la <Terme id="classe-parente">classe parente</Terme> est `KartPlayerController`. Dans son panneau Details, catégorie **Kart > UI**, tu trouveras `Countdown Widget Class` et `Race Hud Widget Class`.

Pour l'instant, le menu déroulant ne te propose aucun widget : `WBP_Countdown` et `WBP_RaceHud` n'existent pas encore, et ils devront hériter des classes C++ qu'on écrit dans les leçons suivantes. Tu reviendras remplir ces cases à la fin du header de chaque widget.

## Dans l'éditeur : le GameMode doit utiliser ce Blueprint

Le constructeur de `AKartGameMode` choisit `AKartPlayerController::StaticClass()` comme classe de PlayerController : c'est la classe **C++**, dont les deux cases sont vides. Si on en reste là, aucun widget ne s'affichera.

Pour que ce soit `BP_KartPlayerController` qui soit créé, choisis-le dans le champ **Player Controller Class** du Blueprint du GameMode utilisé par le niveau (ou dans World Settings > GameMode Override).
