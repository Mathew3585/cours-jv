Chaque widget du jeu existe en **deux morceaux** : une classe C++ et un <Terme id="widget-blueprint">Widget Blueprint</Terme>. La classe C++ contient la logique : quand se montrer, quel texte écrire. Le Widget Blueprint contient l'apparence : la police, la taille, la couleur, la place à l'écran. Le Blueprint **hérite** de la classe C++, exactement comme `BP_KartPlayerController` hérite de `AKartPlayerController`.

Ce partage est pratique : on peut refaire tout le look dans l'éditeur sans toucher au C++. Mais le C++ et le Blueprint doivent être **d'accord** sur les noms. On écrit d'abord le header du compte à rebours, `KartCountdownWidget.h`, de la ligne 1 à la ligne 43, puis on crée son Widget Blueprint.

## Dans l'éditeur : créer WBP_Countdown

Recompile d'abord le C++ : tant que ce n'est pas fait, l'éditeur ne connaît pas `KartCountdownWidget`.

Dans le Content Browser, clic droit > User Interface > Widget Blueprint. Dans la fenêtre qui demande la <Terme id="classe-parente">classe parente</Terme>, ouvre All Classes et choisis `KartCountdownWidget`. Nomme l'asset `WBP_Countdown`. Si le WBP existe déjà avec `UserWidget` comme parent, ouvre-le, va dans l'onglet Graph, clique sur **Class Settings** et change **Parent Class** dans le panneau Details.

## Le texte CountdownText

Dans l'onglet Designer, place un Canvas Panel puis un widget **Text** dedans. Dans la hiérarchie (ou en haut du panneau Details), renomme-le `CountdownText`, lettre pour lettre, comme à la ligne 22 du header. Le type compte aussi : ce doit être un Text, pas une Image ni un Rich Text.

Compile le WBP. Si le nom ou le type ne correspond pas, le compilateur du Blueprint affiche une erreur qui dit qu'un widget requis par la classe parente est introuvable. C'est voulu : <Terme id="bindwidget">BindWidget</Terme> transforme une faute de frappe en erreur visible, au lieu d'un pointeur vide qui ferait planter le jeu.

## Style, Class Defaults et event

Police, taille et ancrage du texte se règlent dans le Designer. `Go Text` et `Go Display Time` sont dans **Class Defaults**, catégorie Kart > Countdown : c'est là que tu changes « GO! » ou sa durée, sans recompiler.

Optionnel : dans le Graph, ajoute l'event **On Countdown Number Shown** pour jouer une animation ou un son à chaque chiffre. Enfin, ouvre `BP_KartPlayerController` et choisis `WBP_Countdown` dans la case `Countdown Widget Class`.

<Encadre type="piege">
Les trois erreurs classiques : le WBP a encore `UserWidget` comme classe parente (il n'apparaît pas dans la case du PlayerController) ; le texte s'appelle `TextBlock_0` ou `Countdown_Text` au lieu de `CountdownText` (le WBP ne compile plus) ; tu as modifié le header puis oublié de recompiler le C++ avant d'ouvrir le WBP (l'éditeur ne connaît pas encore la nouvelle variable).
</Encadre>

<Encadre type="plus-loin">
Il existe aussi `meta = (BindWidgetOptional)` : Unreal remplit le pointeur si l'élément existe, sinon il le laisse à `nullptr` sans erreur. C'est utile pour un élément facultatif, mais il faut alors vérifier le pointeur avant chaque usage. Notre projet n'utilise que `BindWidget` : chaque texte est obligatoire.
</Encadre>
