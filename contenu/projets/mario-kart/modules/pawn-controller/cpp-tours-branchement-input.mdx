## Course : compter les tours

Sur le circuit, la zone 0 est la ligne d'arrivée, et les zones 1, 2, 3... sont des checkpoints à passer dans l'ordre. Le kart retient le prochain checkpoint attendu dans `NextCheckpoint`, et le tour en cours dans `CurrentLap`.

  <Etape lignes="112" titre="Un bandeau de section">
    Un simple commentaire pour se repérer dans un long fichier. On en verra d'autres plus bas (Input, Étapes du Tick, Saut...).
  </Etape>
  <Etape lignes="114-117" titre="EnterLapZone : lire le GameMode">
    Une zone de tour appelle cette fonction en donnant son numéro, `ZoneIndex`. On récupère le GameMode de kart, comme dans BeginPlay : on a besoin de lui pour savoir si la course a commencé et combien il y a de checkpoints.
  </Etape>
  <Etape lignes="119-123" titre="Quand les zones ne comptent pas">
    Pas de GameMode de kart, course pas encore lancée, ou course déjà finie pour ce kart : on sort tout de suite avec `return`. Le `||` signifie « ou » : une seule condition vraie suffit.
  </Etape>
  <Etape lignes="125-129" titre="Le checkpoint attendu">
    Si la zone traversée est exactement celle qu'on attendait, on passe à la suivante : `++NextCheckpoint` ajoute 1.
  </Etape>
  <Etape lignes="130-134" titre="La ligne d'arrivée">
    Si c'est la zone 0 **et** que `NextCheckpoint` a dépassé le nombre de checkpoints, tous ont été passés : le tour est fini, on appelle `CompleteLap`.
  </Etape>
  <Etape lignes="136-138" titre="Tout le reste est ignoré">
    Un checkpoint dans le désordre (raccourci, demi-tour) ou la ligne d'arrivée sans avoir fait le tour : aucun `else`, donc rien ne se passe. L'accolade ferme la fonction.
  </Etape>
  <Etape lignes="140-146" titre="CompleteLap : les vérifications">
    On récupère le GameMode, cette fois sans `const` : on va l'appeler pour lui signaler l'arrivée. Sans GameMode ou si la course est déjà finie, on s'arrête.
  </Etape>
  <Etape lignes="148-149" titre="Repartir du premier checkpoint">
    Un nouveau tour commence : il faudra repasser tous les checkpoints, en commençant par le 1.
  </Etape>
  <Etape lignes="151-158" titre="C'était le dernier tour">
    Si le tour en cours est le dernier, la course est finie pour ce kart. On le note, on garde le temps de course donné par le GameMode, et on prévient le GameMode avec `NotifyKartFinished(this)` : `this` désigne notre kart.
  </Etape>
  <Etape lignes="160-161" titre="Sinon, tour suivant">
    Ce n'était pas le dernier tour : on passe au suivant.
  </Etape>
  <Etape lignes="163-169" titre="ResetRaceProgress">
    Remet le kart au tour 1, au premier checkpoint, course pas finie et temps d'arrivée à 0. Utile quand une course recommence.
  </Etape>
</CodePasAPas>
